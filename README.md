# PlatformOps Lab

A production-style DevOps platform demonstrating cloud infrastructure engineering practices entirely on a local workstation.

## Stack

- Docker
- Docker Compose
- Terraform
- GitHub Actions
- Prometheus
- Grafana
- Loki
- Node.js
- Nginx

## Features

- Infrastructure as Code
- CI/CD
- Monitoring
- Logging
- Containerization
- Local Platform Engineering
- Health Checks
